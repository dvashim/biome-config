Target Biome 2.5.9 and add the four new rules that are in scope

- **Target:** Advance the `$schema` URL to 2.5.9 across all six dist configs, `biome.json`, and the README.
- **Rule:** Add `noUnsafeTypeAssertion` (`warn` in strict, `off` in balanced) — disallows every TypeScript type assertion except `as const`. Balanced turns it off: measured over 443 files of real React/TypeScript library code it produced 72 diagnostics, essentially all of them assertions that bridge a gap in a third-party or generic type (d3 domain tuples, `Object.entries` results, slot forwarding, generic reducers), where `satisfies`, type predicates, and assertion functions do not apply.
- **Rule:** Add `useControlLabel` (`warn` in strict and balanced) — reports a `button` or `menuitem` with no accessible label, in JSX and HTML alike. A label from text content, `aria-label`, `aria-labelledby`, or `title` satisfies it, and anything it cannot resolve statically is assumed to provide one.
- **Rule:** Add `useNamedLayer` (`warn` in strict and balanced) — disallows anonymous CSS cascade layers. An anonymous layer takes a slot in the cascade that no later rule can append to or reorder.
- **Rule:** Add `useTailwindShorthandClasses` (`warn` in strict and balanced) — suggests a single shorter utility for functionally equivalent pairs, such as `size-4` for `w-4 h-4`.
- **Omitted:** `useAstroClientOnlyDirectiveValue`, the fifth rule 2.5.9 adds, is excluded — its only domain is `astro`, and these presets exclude rules exclusive to non-React frameworks. 2.5.9 is the release that introduces Biome's `astro` domain.
- **Scope:** These are the only rules 2.5.9 adds. None were renamed, graduated out of nursery, or removed, and the release adds no formatter, assist, or `files` option, and no option on any rule the presets already list.
- **Stable variants:** All four additions are nursery, so `react-strict-stable` and `react-balanced-stable` are unchanged apart from their `$schema` line.
- **Gating:** Like most framework rules these presets enable by name, `useTailwindShorthandClasses` ignores its dependency gate — it reports the same with and without `tailwindcss` in your `package.json`. It stays quiet for projects that do not use Tailwind anyway, because it only matches strings that already read as Tailwind utility classes.
- **Inherited from Biome:** The HTML formatter changed in six ways, so **every** preset — including `recommended`, `react-recommended`, and both `-stable` variants, whose rule lists do not move — can format HTML differently than on 2.5.8. Blank lines between comment groups and after elements with trailing spaces are preserved; whitespace handling is fixed for `marquee`, `noscript`, `video`, `audio`, and `object`; text wrapping accounts for the width of an adjacent closing tag; a wrap no longer inserts rendered whitespace between an element and touching text; and a parent wraps when it starts or ends with a block-like child such as `source`, `track`, or `param`.
- **Inherited from Biome:** The Tailwind parser now understands container-query variants (`@sm:`, `@max-lg:`, `@min-[400px]:`), child and descendant variants (`*:`, `**:`), the legacy leading `!` important marker, combinators and modifiers in arbitrary variants, and modifiers on bare utilities. Classes the 2.5.8 parser could not read now parse, so `useSortedClasses` can order them differently.
- **Inherited from Biome:** The CSS parser now recovers at declaration boundaries after a bogus declaration, and accepts Tailwind container-query names in `@variant` such as `@xl`, which previously raised a parse error and a spurious `noUnknownAtRules` diagnostic.
- **Inherited from Biome:** Several fixes make rules these presets activate report less, and need nothing from you — `noComponentHookFactories` only reports a `use`-prefixed variable when a function is assigned directly, `useExpect` recognizes Vitest Browser Mode `expect.element()`, `useJsxKeyInIterable` no longer reports Astro files, `noSvgWithoutTitle` accepts the `aria-hidden` boolean shorthand, and `useGenericFontNames` accepts the `math` generic family.
