# Proposal

## Why

The presets target Biome 2.5.14 while 2.5.15 is current, so the eight rules it adds
within the presets' groups reach no team through a preset, and nothing from the
package tells teams what else 2.5.15 changes for them. This change is the 2.5.15
slice of the shared intent. Intent: `intent.md`; shared intent:
`docs/intents/0001-keep-presets-current.md`.

## What Changes

- **Target Biome 2.5.15.** Advance the `$schema` URL in all six `dist/*.json`
  presets and in `biome.json`, the seven Biome version references in `README.md`,
  and the declared `@biomejs/biome` range in `package.json` (`^2.5.14` → `^2.5.15`)
  with its lockfile specifier. The lockfile already resolves 2.5.15 (PR #216).
- **Regenerate the rule catalogue** (`audit/rule-metadata.json`) against 2.5.15 —
  546 → 557 rules. Two existing entries also change their example languages
  (`useAltText` gains Astro; `useReactCompiler` loses JSON); neither changes scope.
- **Account for all eleven new rules.** All eleven are nursery; 2.5.15 removes,
  renames, and moves none, and it directly follows 2.5.14, so there is no
  intermediate release to diff.
  - **Enable eight** in `react-strict` at `warn` and in `react-balanced`:
    `noMeaninglessVoidOperator`, `noMisplacedListElements`,
    `noReactObjectTypeAsDefaultProp`, `noSelfImport`, `noTailwindRawColors`,
    `useLogicalProperties`, `usePromiseRejectErrors`, `useStrictBooleanExpressions`.
    Balanced turns three of them `off` — `noTailwindRawColors`,
    `useLogicalProperties`, `useStrictBooleanExpressions` — and keeps five at
    `warn`. Each level and its evidence live in `design.md`.
  - **Leave out three** on their published domains, with no ledger entry:
    `noAstroConflictingSetDirectives` (`astro`), and `noSvelteExportLet` and
    `useSvelteKitRuneImports` (`svelte`).
- **Record the option audit's one finding.** 2.5.15 removes both options
  (`attributes`, `functions`) from `noTailwindArbitraryValue`, which both parents
  list. No preset sets either, so no preset entry changes.
- **Keep the `-stable` presets at their current 180 rules.** Every addition sits in
  `nursery`, which the `-stable` variants drop, so they change only in `$schema`.
- **Reconcile every count the README publishes** — 280 → 288 configured rules,
  nursery 100 → 108, balanced relaxations 25 → 28 with the stable-category subset
  still 15 — and add the three relaxations to the table and its nursery note.
- **Correct the README's `useReactCompiler` claim.** It says the rule stays silent
  unless `react` is a dependency. Measured against 2.5.15, it reports with React 18
  declared and with no `package.json` at all.
- **Correct the maintainer statements 2.5.15 makes untrue**: `CLAUDE.md`'s
  description of `useReactCompiler` as the rule that still gates itself, and its
  count of 33 listed rules in domains the standing requirement never names, which
  becomes 36 — a count a comment in `scripts/check-presets.ts` repeats. Both
  counts are reworded to carry no number.
- **Release a `minor`** whose changeset leads with the Biome ≥ 2.5.15 requirement
  and names each of the eleven new rules, each balanced relaxation, and each
  inherited 2.5.15 change a team would notice, grouped by the presets it reaches —
  including the two that stop a team's own settings working: a domain set to
  `"none"` no longer turns off rules the presets list, and a configuration that sets
  `noTailwindArbitraryValue`'s removed options no longer loads.
- **Audit configuration migrations** by previewing `biome migrate` against every
  preset and `biome.json`.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. The standing requirements in `linter-rule-coverage` govern this pass
unchanged: it applies them to 2.5.15 without altering any. No standing requirement
names `useReactCompiler`; the one that allows a rule to gate itself at runtime stays
true as a general statement. The change therefore sets `skip_specs: true` rather
than inventing a requirement to satisfy validation.

## Impact

- `dist/biome.react-strict.json`, `dist/biome.react-balanced.json` — eight nursery
  entries each, and `$schema`.
- `dist/biome.recommended.json`, `dist/biome.react-recommended.json` — `$schema`
  only.
- `dist/biome.react-strict-stable.json`, `dist/biome.react-balanced-stable.json` —
  regenerated by `pnpm sync-stable`; `$schema` only.
- `biome.json` — `$schema`.
- `package.json`, `pnpm-lock.yaml` — the `@biomejs/biome` range and its lockfile
  specifier only. The working tree already holds that edit beside unrelated
  dev-tool bumps (`@types/node`, `publint`, pnpm 12.9.1, the regenerated OpenSpec
  assets); those are not part of this change and land separately.
- `audit/rule-metadata.json` — regenerated. `audit/rule-exclusions.json` —
  unchanged.
- `README.md` — version references, counts and totals, the relaxation table and its
  notes, and the `useReactCompiler` highlight.
- `CLAUDE.md` — two sentences. `scripts/check-presets.ts` — one comment, with no
  change in behaviour.
- `.changeset/` — one `minor` changeset.
- Not touched: the standing specs, and the behaviour of any script.
- Teams: users of `react-strict` receive the eight rules as new diagnostics, users
  of `react-balanced` five of them; users of every preset receive 2.5.15's
  formatter, parser, configuration-handling, and rule-behaviour changes.
